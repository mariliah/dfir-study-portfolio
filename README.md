# DFIR Portfolio
Using Claude, I have created a study guide to teach myself digital forensics, and deepen my knowledge in incident response. <br>

I have decided to do a mixture of ethical hacking courses, and use digital forensic tools to study how an attack might look like on the defense side.

I am using some paid resources, but most are free, and they are linked below.

## Resources
* [Practical Ethical Hacking](https://tcm-sec.com/academy/practical-ethical-hacking/)
* [NIST SP 800-86](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-86.pdf)
* [Over The Wire](https://overthewire.org/wargames/bandit/)
* [PorSewigger learning paths](https://portswigger.net/web-security/learning-paths)
  - Server-side vulnerabilities
  - SQL Injection
  - Authentication vulnerabilities
  - File upload vulnerabilities
